## 三、后台功能地图（核心资产）

### 3.1 仪表盘
报价总数、草稿数 / 已发出 / 已暂停 / 已成交 / 未成交、赢单率、报价转化率（`(总数-草稿)/总数`）、分类金额占比（硬装工程 / 主材项目 / 软装项目）、时间筛选（本月 / 本季 / 本年 / 全部）。

### 3.2 智能造价（AI 估算主流程）
```
选择智能套餐 → 输入城市 + 面积 + 户型 + 楼龄 + 楼层
             → 维护空间清单（可 AI 自动拆解户型）
             → 写现场备注（老房年数、空鼓、承重墙限制、智能预留…）
             → AI 综合生成报价草稿（10-15 秒）
             → 一键转为正式报价
```
附带能力：智能匹配模板（本地算法，**免费不扣点数**）、面积偏差校验、装修类型一致性校验、未含项预算提醒（家电/家具/定制柜/空调/灯具）。

### 3.3 报价管理（最重的模块）
- **完整状态机**：`草稿 → 待审批 → 已通过/已驳回 → 终稿 → 已签发 → 已成交/未成交/已暂停/已放弃`，另支持归档、变更单（change-order）
- **明细编辑**：分类分组（拆除 / 水电 / 泥木 / 油漆 / 安装…）、条目增删改、数量、单位、售价、成本、毛利
- **付款条款**：`payment-terms` 多期收款计划
- **审计与用量**：`pricing-audit` 定价审计、`material-takeoff` 材料用量清单
- **导出分享**：Excel / PDF 导出（按次解锁）、客户报价页分享链接（含解锁码）
- **历史版本**：`history` 变更留痕

### 3.4 报价体检（差异化亮点）
- **本地体检（免费不扣点数）**：成本快照、毛利可信度、人工分摊、材料用量
- **AI 深度复核（扣点数）**：漏项检查、异常单价、客户解释建议 —— 只给建议，不改数据

### 3.5 模板管理（户型模板）
空间配置模板（客厅/主卧/厨房/卫生间/阳台…+ 自定义空间如影音室、衣帽间），支持本地匹配打分、AI 生成新模板（10 点）、面积偏差校验。

### 3.6 工艺价格库
分类 + 条目结构（名称 / 单位 / 参考价 / 成本价 / 工艺说明 / 材料用量），支持：
- 城市价格校准（AI，5 点）
- 价格库 AI 体检（5 点）
- Excel 导入、预设套用、重置
- 人工工资标准配置（日工资 / 人数 / 天数 → 建议成本）

### 3.7 客户管理
客户档案 CRUD、客户关联报价列表、跟进记录。

### 3.8 会员与计费
订阅套餐、点数包（奇豆）、出单次数包、订单支付/取消/标记已付、发票管理、退款申请与审核。

### 3.9 平台管理后台（admin）
总览、用户管理（启停 / 角色 / 平台管理员）、组织管理（改套餐 / 改状态）、点数发放、退款审核。

## 四、AI 能力清单（15+ 项，按"奇豆"计费）

| 分组 | 功能 | 说明 |
|---|---|---|
| 估算 | 完整自助估算 | 城市+面积+户型+空间+备注 → 综合造价 |
| 估算 | 户型智能拆解 | 一句话户型自动拆出各空间面积 |
| 估算 | 装修档次匹配 | 简装 / 中档 / 高档 三档价格区间对比 |
| 估算 | 预算反推 | 业主给硬预算 → 评估可行性 + 分项资金分配 |
| 估算 | 增项风险预测 | 老房/楼层/季节等隐性增项，预估额外费用 |
| 报价辅助 | 自然语言加项 | "客厅墙面刷乳胶漆35平米加踢脚线" → 结构化条目 |
| 报价辅助 | 单点价格建议 | 单个工艺项的城市级价格区间 |
| 报价辅助 | 相似项推荐 | 编辑器选中某项 → 推荐相似工艺项 |
| 审核 | 整张报价复核 | 综合评分 + 漏项 + 异常，输出 JSON 结果 |
| 审核 | 漏项检查 | 检查分类完整性、关键工序是否齐全 |
| 审核 | 客户话术润色 | 内部工艺名 → 业主看得懂的话术 |
| 管理视角 | AI 用量看板 | token 消耗、成本（人民币）、按功能/用户/日聚合 |
| 管理视角 | 配额状态 | 套餐、月度调用、当前是否放行 |
| 管理视角 | 审计异常预警 | 识别反复改价、异常操作 |
| 其他 | 价格库体检 / 城市校准 / 模板 AI 生成 | 5 点 / 5 点 / 10 点 |

**计费原则**：成功才扣，失败不扣；调用前展示本次消耗点数；点数不足引导充值或升级 Plus。

## 五、商业化设计（三层计费，值得抄）

### 套餐档位

| | 免费版 | 普通版（按次） | **Plus 版** | 企业版 |
|---|---|---|---|---|
| 价格 | ¥0 永久 | **¥9.9 / 1 次出单** | 月付 **¥38** / 年付 **¥32/月（年总 388）** | 定制 |
| 账号 | 1 | 1 | 1 | 5 起 |
| 出单导出 | 需买次数 | 9.9 元 1 次（解锁后反复导） | 不限次 | 不限次 |
| 模板 | 1 套示例 | 10 套 | 10 套 | 企业库 |
| 价格库 | 示例库 | 可编辑个人库 | 个人库+常用分类 | 企业统一库 |
| AI 点数 | 赠 30/月 | 按点计费 | 赠 1000/月 | 赠 5000/月 |
| 历史报价 | 近 7 天 | 长期 | 长期+一键复用 | 长期+版本管理 |
| 毛利可见 | 不开放 | 本人可见 | 本人可见 | 按角色 |
| 审批流 | — | — | — | 老板审批 |

### 三层计费模型
1. **订阅费**（月/年，解锁不限次）
2. **出单次数包**（¥9.9/次，不订阅也能用）
3. **AI 奇豆包**（180 天有效，AI 功能单独扣）

> 这是很精明的设计：低价按次降低首次付费门槛，订阅锁住高频用户，AI 点数做增量收入。

## 七、值得抄 vs 可以超越

### 值得抄
1. **三层计费** —— 按次 + 订阅 + 点数，覆盖所有付费意愿层级
2. **报价状态机** —— 从草稿到成交/输单，真实还原装企业务流程
3. **本地体检免费 + AI 复核收费** —— 免费钩子引流，AI 做溢价
4. **点数不足时的引导**（"充值奇豆" / "升级 Plus"）—— 转化路径清晰
5. **AI 免责声明 + 输出需人工复核** —— 合规且降低责任风险
6. **未含项提醒**（家电/家具/定制柜另计）—— 减少客户纠纷，专业感强

### 可以超越
1. **界面**：原站是典型的 Tailwind + 自研组件，视觉偏"工具感"，配色紫蓝渐变、卡片阴影较重 → 可做更现代的浅色精致风格
2. **性能**：764KB 单包 JS，无代码分割 → 可做按需加载
3. **移动端**：工作台明显为桌面设计 → 可做响应式适配
4. **离线/本地**：可加本地缓存草稿
5. **数据可视化**：原站图表是 CSS 进度条 → 可用轻量图表提升专业感
6. **报价单模板**：客户报价页可做得更像"作品"
